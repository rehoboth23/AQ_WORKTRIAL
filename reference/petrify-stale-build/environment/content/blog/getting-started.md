# Getting Started with Blogging

Creating a blog with Petrify is straightforward. This guide walks you
through the entire process from installation to your first post.

## Creating Your First Post

Create a new Markdown file in the `content/blog/` directory with YAML
frontmatter specifying the title, date, and type.

## Previewing Your Site

Run the build command and open the output directory with a local server
to preview your changes before deploying.

# Vendor Fee Calculator Replacement

A vendor's closed-source tax-and-fee calculator binary (`feecalc`) is installed at `/usr/local/bin/feecalc`. The procurement team needs an open Python replacement before the vendor contract expires. No source code or documentation is available — only the binary and a folder of sample orders.

## Goal

Create `/app/quotelib.py` that behaves identically to `feecalc` for any order input. Specifically, for any input of the kinds shown in `/app/sample.txt`, your program must produce **exactly the same stdout, stderr, and exit status** as `/usr/local/bin/feecalc`.

## Input Format

The program reads text lines from stdin:

- `STATE=<2-letter code>` — US state code
- `TYPE=<retail|wholesale|government>` — customer type
- `TAX_EXEMPT=<true|false>` — optional, tax-exempt flag
- `PAYMENT=<credit_card|debit|ach|cash|gift_card>` — payment method
- `SHIP_METHOD=<standard|express|overnight>` — shipping method
- `SHIP_ZONE=<1-5>` — shipping zone
- `COUPON=<code>` — optional, coupon code
- `ITEM <category> <quantity> <unit_price>` — one or more item lines

Categories: `general`, `food`, `clothing`, `medicine`. Prices are in dollars with optional cents (e.g., `10.00`, `5`, `3.50`).

Blank lines and unrecognized lines are ignored.

## Output Format

On success (exit 0), write exactly 12 lines to stdout, each as `KEY=<amount>` with amounts formatted to exactly 2 decimal places (e.g., `100.00`, `-0.55`, `0.00`):

```
SUBTOTAL=<amount>
QTY_DISCOUNT=<amount>
BULK_DISCOUNT=<amount>
COUPON_DISCOUNT=<amount>
TAXABLE=<amount>
TAX=<amount>
SHIPPING=<amount>
FUEL=<amount>
HANDLING=<amount>
SMALL_ORDER_FEE=<amount>
PAYMENT_SURCHARGE=<amount>
TOTAL=<amount>
```

On validation error (exit 1), write `ERROR: <message>` to stderr and **nothing** to stdout.

## Module Interface

The program must also be importable as a Python module:

```python
from quotelib import calculate
output = calculate(text: str) -> str  # returns the 12-line output string
# raises ValueError with the error message on invalid input
```

When run as a script (`python3 /app/quotelib.py`), it reads from stdin and writes to stdout/stderr with the same contract as `feecalc`.

## Sample File

`/app/sample.txt` contains example orders separated by lines containing only `===`. Each block is a complete order that should be fed individually to `feecalc`. The sample covers every kind of input your program must handle, but does **not** exhaust every edge case — you must probe the binary to discover all rules.

## Rules

1. Your program must **not** call `feecalc` or any external program.
2. The `feecalc` binary will **not** be available when your program is checked.
3. Probe the binary systematically to discover every rule: tax rates by state, category exemptions by state, quantity discount tiers, bulk discount tiers, coupon codes and their logic, shipping rates, fuel surcharge, handling fees, small order fees, payment surcharges, fee caps, rounding behavior, and error handling.
4. Every rule that affects output is observable by running the binary on inputs you can construct.
5. The comparison is byte-for-byte: stdout, stderr, and exit code must all match exactly.

## How to Probe

Feed individual order blocks to the binary:

```bash
printf 'STATE=CA\nTYPE=retail\nPAYMENT=cash\nSHIP_METHOD=standard\nSHIP_ZONE=1\nITEM general 1 10.00\n' | /usr/local/bin/feecalc
```

Split the sample file on `===` lines and feed each block individually:

```bash
awk 'BEGIN{RS="==="} NF{print}' /app/sample.txt | while IFS= read -r line; do
  printf '%s' "$line" | /usr/local/bin/feecalc
  echo "exit: $?"
done
```

Or more reliably:

```bash
python3 -c "
data = open('/app/sample.txt').read()
for block in data.split('==='):
    block = block.strip()
    if block:
        import subprocess
        r = subprocess.run(['/usr/local/bin/feecalc'], input=block, capture_output=True, text=True)
        print(repr(block[:40]), 'rc=', r.returncode)
        print(r.stdout, end='')
        if r.stderr: print('STDERR:', r.stderr, end='')
        print('---')
"
```

Vary inputs systematically: change states, customer types, quantities at tier boundaries, subtotals at discount thresholds, categories in different states, coupons with subtotals just above and below minimums, payment methods, shipping methods, and zones. Test exact boundary values and combinations the sample doesn't cover.

#!/usr/bin/env python3
"""Vendor fee calculator replacement - Python reimplementation of feecalc."""

import sys

TAX_RATES = {
    "CA": 725, "TX": 625, "NY": 800, "FL": 600, "WA": 650,
    "OR": 0, "MA": 625, "IL": 625, "PA": 600, "OH": 575,
}

SHIP_TABLE = {
    "standard":  [500, 850, 1200, 1550, 2000],
    "express":   [1000, 1500, 2000, 2500, 3200],
    "overnight": [2000, 2800, 3800, 4800, 6000],
}

PAY_RATES = {
    "credit_card": 250, "debit": 0, "ach": -50,
    "cash": 0, "gift_card": 100,
}

FOOD_EXEMPT_STATES = {"CA", "NY", "MA", "PA"}
CLOTHING_EXEMPT_STATES = {"PA"}
SHIP_TAXED_STATES = {"TX", "FL", "OH"}


def rhaz(a, b, d):
    """Round half away from zero: compute round(a * b / d)."""
    if d == 0:
        return 0
    prod = a * b
    q, r = divmod(prod, d)
    if prod < 0 and r != 0:
        q += 1
        r -= d
    if prod >= 0:
        if 2 * r >= d:
            q += 1
    else:
        if 2 * r <= -d:
            q -= 1
    return q


def parse_price(s):
    """Parse a price string to cents, matching C's parse_price."""
    p = s.lstrip(' \t')
    neg = False
    if p.startswith('-'):
        neg = True
        p = p[1:]
    whole = 0
    i = 0
    while i < len(p) and p[i].isdigit():
        whole = whole * 10 + int(p[i])
        i += 1
    frac = 0
    fd = 0
    if i < len(p) and p[i] == '.':
        i += 1
        while i < len(p) and p[i].isdigit() and fd < 2:
            frac = frac * 10 + int(p[i])
            fd += 1
            i += 1
    cents = whole * 100 + (frac * 10 if fd == 1 else frac)
    if neg:
        cents = -cents
    return cents


def fmt(cents):
    """Format cents as a dollar string with 2 decimal places."""
    neg = cents < 0
    if neg:
        cents = -cents
    s = f"{cents // 100}.{cents % 100:02d}"
    if neg:
        s = "-" + s
    return s


def _atoi(s):
    """C-style atoi."""
    s = s.lstrip()
    if not s:
        return 0
    sign = 1
    i = 0
    if s[0] == '-':
        sign = -1
        i = 1
    elif s[0] == '+':
        i = 1
    result = 0
    while i < len(s) and s[i].isdigit():
        result = result * 10 + int(s[i])
        i += 1
    return sign * result


def _parse_llong(s):
    """Parse a string as a C long long (%lld behavior)."""
    s = s.lstrip()
    if not s:
        return None
    sign = 1
    i = 0
    if s[0] == '-':
        sign = -1
        i = 1
    elif s[0] == '+':
        i = 1
    if i >= len(s) or not s[i].isdigit():
        return None
    result = 0
    while i < len(s) and s[i].isdigit():
        result = result * 10 + int(s[i])
        i += 1
    return sign * result


def calculate(text):
    """Calculate fees for an order.

    Args:
        text: Input text with key=value lines and ITEM lines.

    Returns:
        String with 12 output lines.

    Raises:
        ValueError: On validation error, with the error message.
    """
    state = ""
    state_set = False
    ctype = ""
    type_set = False
    texempt = False
    texempt_set = False
    pay = ""
    pay_set = False
    smeth = ""
    smeth_set = False
    zone = 0
    zone_set = False
    coup = ""
    coup_set = False
    items = []

    for line in text.split('\n'):
        line = line.rstrip('\r')
        if len(line) == 0:
            continue

        if line.startswith("STATE="):
            state_set = True
            state = line[6:69]
        elif line.startswith("TYPE="):
            type_set = True
            ctype = line[5:68]
        elif line.startswith("TAX_EXEMPT="):
            texempt_set = True
            texempt = (line[11:] == "true")
        elif line.startswith("PAYMENT="):
            pay_set = True
            pay = line[8:71]
        elif line.startswith("SHIP_METHOD="):
            smeth_set = True
            smeth = line[12:75]
        elif line.startswith("SHIP_ZONE="):
            zone_set = True
            zone = _atoi(line[10:])
        elif line.startswith("COUPON="):
            coup_set = True
            coup = line[7:70]
        elif line.startswith("ITEM "):
            if len(items) < 1024:
                parts = line[5:].split()
                if len(parts) >= 3:
                    cat = parts[0][:63]
                    q = _parse_llong(parts[1])
                    if q is not None:
                        price_cents = parse_price(parts[2][:63])
                        ext_cents = q * price_cents
                        items.append([cat, q, price_cents, ext_cents, 0])

    if not state_set:
        raise ValueError("missing STATE")
    if not type_set:
        raise ValueError("missing TYPE")
    if not pay_set:
        raise ValueError("missing PAYMENT")
    if not smeth_set:
        raise ValueError("missing SHIP_METHOD")
    if not zone_set:
        raise ValueError("missing SHIP_ZONE")
    if len(items) == 0:
        raise ValueError("no items")
    if state not in TAX_RATES:
        raise ValueError("unknown state")
    if ctype not in ("retail", "wholesale", "government"):
        raise ValueError("unknown type")
    if pay not in PAY_RATES:
        raise ValueError("unknown payment method")
    if smeth not in SHIP_TABLE:
        raise ValueError("unknown shipping method")
    if zone < 1 or zone > 5:
        raise ValueError("invalid zone")
    for item in items:
        if item[1] < 0:
            raise ValueError("negative quantity")
    for item in items:
        if item[2] < 0:
            raise ValueError("negative price")

    tqd = 0
    for item in items:
        q = item[1]
        if q >= 50:
            p = 10
        elif q >= 10:
            p = 5
        else:
            p = 0
        qty_disc = rhaz(item[3], p, 100)
        item[4] = qty_disc
        tqd += qty_disc

    sub = sum(item[3] for item in items)
    pq = sub - tqd

    ws = (ctype == "wholesale")
    if ws:
        if pq >= 50000:
            bp = 5
        elif pq >= 25000:
            bp = 3
        else:
            bp = 0
    else:
        if pq >= 100000:
            bp = 5
        elif pq >= 50000:
            bp = 3
        else:
            bp = 0
    bd = rhaz(pq, bp, 100)
    pb = pq - bd

    cd = 0
    fs = False
    if coup_set and coup:
        if coup == "SAVE10":
            cd = rhaz(pb, 10, 100)
        elif coup == "SAVE20":
            if pb >= 10000:
                cd = rhaz(pb, 20, 100)
        elif coup == "DOLLAR5":
            if pb >= 5000:
                cd = 500
        elif coup == "DOLLAR25":
            if pb >= 20000:
                cd = 2500
        elif coup == "FREESHIP":
            fs = True

    ds = pb - cd

    shp = SHIP_TABLE[smeth][zone - 1]
    if fs:
        shp = 0

    fuel = rhaz(shp, 10, 100)
    if fuel > 500:
        fuel = 500

    tq = sum(item[1] for item in items)
    hdl = 200 + 50 * tq
    if hdl > 1000:
        hdl = 1000

    gov = (ctype == "government")
    sof = 0
    if sub < 2500 and not gov:
        sof = 500

    exm = 0
    for item in items:
        cat = item[0]
        ex = False
        if cat == "food" and state in FOOD_EXEMPT_STATES:
            ex = True
        elif cat == "clothing" and state in CLOTHING_EXEMPT_STATES:
            ex = True
        elif cat == "medicine" and state != "WA":
            ex = True
        if ex:
            exm += item[3] - item[4]

    if gov or texempt:
        txbl = 0
        tax = 0
    else:
        txbl = ds - exm
        if state in SHIP_TAXED_STATES:
            txbl += shp
        tax = rhaz(txbl, TAX_RATES[state], 10000)

    pp = ds + tax + shp + fuel + hdl + sof
    ps = rhaz(pp, PAY_RATES[pay], 10000)
    tot = pp + ps

    lines = [
        f"SUBTOTAL={fmt(sub)}",
        f"QTY_DISCOUNT={fmt(tqd)}",
        f"BULK_DISCOUNT={fmt(bd)}",
        f"COUPON_DISCOUNT={fmt(cd)}",
        f"TAXABLE={fmt(txbl)}",
        f"TAX={fmt(tax)}",
        f"SHIPPING={fmt(shp)}",
        f"FUEL={fmt(fuel)}",
        f"HANDLING={fmt(hdl)}",
        f"SMALL_ORDER_FEE={fmt(sof)}",
        f"PAYMENT_SURCHARGE={fmt(ps)}",
        f"TOTAL={fmt(tot)}",
    ]
    return '\n'.join(lines) + '\n'


def main():
    try:
        text = sys.stdin.read()
        output = calculate(text)
        sys.stdout.write(output)
    except ValueError as e:
        sys.stderr.write(f"ERROR: {e}\n")
        sys.exit(1)


if __name__ == "__main__":
    main()

def _order(state="CA", ctype="retail", payment="cash", smeth="standard",

    lines = [

    cases.append(_order(coupon="DOLLAR25", items=["ITEM general 1 200.00"]))

    # --- Multi-item orders with mixed categories ---
    for state in STATES:
        cases.append(_order(
            state=state,
            items=[
                "ITEM general 5 20.00",
                "ITEM food 10 10.00",
                "ITEM clothing 3 30.00",
                "ITEM medicine 2 50.00",
            ],
        ))

    # --- ACH negative surcharge ---
    for cents in [1000, 5000, 10000, 50000, 100000]:
        cases.append(_order(payment="ach", items=[f"ITEM general 1 {_price_str(cents)}"]))

    # --- Error cases ---
    cases.append("TYPE=retail\nPAYMENT=cash\nSHIP_METHOD=standard\nSHIP_ZONE=1\nITEM general 1 10.00")  # missing STATE
    cases.append("STATE=CA\nPAYMENT=cash\nSHIP_METHOD=standard\nSHIP_ZONE=1\nITEM general 1 10.00")  # missing TYPE
    cases.append("STATE=CA\nTYPE=retail\nSHIP_METHOD=standard\nSHIP_ZONE=1\nITEM general 1 10.00")  # missing PAYMENT
    cases.append("STATE=CA\nTYPE=retail\nPAYMENT=cash\nSHIP_ZONE=1\nITEM general 1 10.00")  # missing SHIP_METHOD
    cases.append("STATE=CA\nTYPE=retail\nPAYMENT=cash\nSHIP_METHOD=standard\nITEM general 1 10.00")  # missing SHIP_ZONE
    cases.append("STATE=CA\nTYPE=retail\nPAYMENT=cash\nSHIP_METHOD=standard\nSHIP_ZONE=1")  # no items
    cases.append(_order(state="ZZ", items=["ITEM general 1 10.00"]))  # unknown state
    cases.append(_order(ctype="business", items=["ITEM general 1 10.00"]))  # unknown type
    cases.append(_order(payment="bitcoin", items=["ITEM general 1 10.00"]))  # unknown payment
    cases.append(_order(smeth="teleport", items=["ITEM general 1 10.00"]))  # unknown shipping
    cases.append(_order(zone="0", items=["ITEM general 1 10.00"]))  # invalid zone 0
    cases.append(_order(zone="9", items=["ITEM general 1 10.00"]))  # invalid zone 9
    cases.append(_order(items=["ITEM general -1 10.00"]))  # negative quantity
    cases.append(_order(items=["ITEM general 1 -10.00"]))  # negative price
    cases.append(_order(items=["ITEM general -5 -20.00"]))  # both negative (qty first)

    # --- Multi-error priority ---
    # missing STATE wins over everything
    cases.append("TYPE=retail\nPAYMENT=bitcoin\nSHIP_METHOD=teleport\nSHIP_ZONE=9\nITEM general -1 -10.00")
    # missing TYPE wins over unknown payment, negative qty
    cases.append("STATE=CA\nPAYMENT=bitcoin\nSHIP_METHOD=standard\nSHIP_ZONE=1\nITEM general -1 10.00")
    # missing PAYMENT wins over unknown shipping, negative qty
    cases.append("STATE=CA\nTYPE=retail\nSHIP_METHOD=teleport\nSHIP_ZONE=1\nITEM general -1 10.00")
    # missing SHIP_METHOD wins over invalid zone, negative qty
    cases.append("STATE=CA\nTYPE=retail\nPAYMENT=cash\nSHIP_ZONE=9\nITEM general -1 10.00")
    # missing SHIP_ZONE wins over no items... wait, no items is checked after SHIP_ZONE
    # Actually: missing SHIP_ZONE, then no items, then unknown state, etc.
    cases.append("STATE=CA\nTYPE=retail\nPAYMENT=cash\nSHIP_METHOD=standard")  # missing SHIP_ZONE + no items
    # no items wins over unknown state
    cases.append("STATE=ZZ\nTYPE=retail\nPAYMENT=cash\nSHIP_METHOD=standard\nSHIP_ZONE=1")
    # unknown state wins over unknown type
    cases.append(_order(state="ZZ", ctype="business", payment="bitcoin", smeth="teleport", zone="9", items=["ITEM general -1 -10.00"]))
    # unknown type wins over unknown payment
    cases.append(_order(ctype="business", payment="bitcoin", items=["ITEM general -1 -10.00"]))
    # unknown payment wins over unknown shipping
    cases.append(_order(payment="bitcoin", smeth="teleport", zone="9", items=["ITEM general -1 -10.00"]))
    # unknown shipping wins over invalid zone
    cases.append(_order(smeth="teleport", zone="9", items=["ITEM general -1 -10.00"]))
    # invalid zone wins over negative quantity
    cases.append(_order(zone="0", items=["ITEM general -1 10.00"]))
    # negative quantity wins over negative price
    cases.append(_order(items=["ITEM general -1 -10.00"]))

    # --- Extra random cases (100) ---
    for _ in range(100):
        state = rng.choice(STATES)
        ctype = rng.choice(TYPES)
        payment = rng.choice(PAYMENTS)
        smeth = rng.choice(SHIP_METHODS)
        zone = rng.choice(ZONES)
        coupon = rng.choice(COUPONS)
        tax_exempt = rng.choice([None, None, None, "true"])
        n_items = rng.randint(1, 3)
        items = []
        for _ in range(n_items):
            cat = rng.choice(CATEGORIES)
            qty = rng.randint(1, 100)
            price_cents = rng.choice([
                1, 8, 50, 100, 200, 350, 500, 725, 1000, 1500, 2000,
                2500, 5000, 7500, 10000, 15000, 20000, 25000, 30000,
                50000, 100000,
            ])
            items.append(f"ITEM {cat} {qty} {_price_str(price_cents)}")
        cases.append(_order(
            state=state, ctype=ctype, payment=payment,
            smeth=smeth, zone=zone,
            coupon=coupon if coupon else None,
            tax_exempt=tax_exempt, items=items,
        ))

    # --- Wholesale with various subtotals ---
    for cents in [10000, 15000, 20000, 24900, 25000, 30000, 49900, 50000, 75000, 100000]:
        cases.append(_order(ctype="wholesale", items=[f"ITEM general 1 {_price_str(cents)}"]))

    # --- Multi-item with various combinations ---
    for _ in range(20):
        state = rng.choice(STATES)
        n = rng.randint(2, 5)
        items = []
        for _ in range(n):
            cat = rng.choice(CATEGORIES)
            qty = rng.choice([1, 5, 10, 15, 50])
            price = rng.choice([5.00, 10.00, 20.00, 50.00, 100.00])
            items.append(f"ITEM {cat} {qty} {price:.2f}")
        cases.append(_order(state=state, items=items))

    return cases

def compare_one(case, ref_executable):
    """Compare reference and artifact on a single case."""
    ref_out, ref_err, ref_rc = run_program(ref_executable, case)
    art_out, art_err, art_rc = run_program(IMAGE_PYTHON, case, is_python=True)
    if ref_out != art_out or ref_err != art_err or ref_rc != art_rc:
        msg = f"Input:\n{case}\n"
        msg += f"--- Reference ---\n"
        msg += f"stdout: {ref_out!r}\n"
        msg += f"stderr: {ref_err!r}\n"
        msg += f"rc: {ref_rc}\n"
        msg += f"--- Artifact ---\n"
        msg += f"stdout: {art_out!r}\n"
        msg += f"stderr: {art_err!r}\n"
        msg += f"rc: {art_rc}\n"
        return False, msg
    return True, ""

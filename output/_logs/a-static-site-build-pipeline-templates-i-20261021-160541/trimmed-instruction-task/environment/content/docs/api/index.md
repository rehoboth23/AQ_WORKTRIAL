# API Reference

Complete reference for the Petrify Python API.

## Modules

- `petrify.builder` — Site building and orchestration
- `petrify.assets` — Asset management and hashing
- `petrify.content` — Content loading and parsing
- `petrify.links` — Navigation and URL generation
- `petrify.config` — Configuration loading
- `petrify.utils` — Shared utilities

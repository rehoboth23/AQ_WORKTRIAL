# About Petrify

Petrify is a modern static site generator built with Python. It transforms
Markdown content with YAML frontmatter into a complete website using Jinja2
templates.

## Features

- Content-based asset hashing for cache-busting
- Automatic navigation link generation
- Blog post ordering and RSS feeds
- Nested page support with correct relative paths

## History

Petrify was created in 2023 as a lightweight alternative to heavier static
site generators. Version 2.0 introduced the current build pipeline.

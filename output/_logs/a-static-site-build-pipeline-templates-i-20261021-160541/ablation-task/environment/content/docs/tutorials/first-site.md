# Your First Site

This tutorial walks you through creating your first static site with
Petrify from start to finish.

## Prerequisites

You will need Python 3.8 or later and a text editor.

## Step 1: Install Dependencies

```bash
pip install PyYAML Python-Markdown Jinja2
```

## Step 2: Create the Project Structure

Set up directories for content, templates, and assets.

## Step 3: Write Content

Add Markdown files with YAML frontmatter to `content/`.

## Step 4: Build

Run `python3 build.py` and open `dist/index.html` in your browser.

# Getting Started

Follow this guide to set up your first Petrify site from scratch.

## Prerequisites

- Python 3.8 or later
- pip package manager

## Installation

Install the required dependencies:

```bash
pip install PyYAML Python-Markdown Jinja2
```

## Creating Content

Add Markdown files with YAML frontmatter to the `content/` directory.

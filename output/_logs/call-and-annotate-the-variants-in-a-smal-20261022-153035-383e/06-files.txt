# Amplicon Variant Annotation

A small diagnostic lab sequences a panel of three genes (ALPHA, BETA, GAMMA) by targeted amplicon sequencing. The lab's variant-annotation pipeline broke when the LIMS was upgraded, and the bioinformatician who maintained it left. You are given the reference genome, the gene annotation, the lab's nomenclature guide and SOP, a vendored read aligner, six practice samples with their expected reports, and an outdated summary file from the previous pipeline.

Your job is to create `/app/annotate.py` — a Python script that takes amplicon reads, calls variants, and produces a report in the lab's exact HGVS-style notation with protein consequences, correct enough that the LIMS can ingest it directly.

## CLI

```
python3 /app/annotate.py --reads <fastq_path> --reference <fasta_path> --annotation <tsv_path> --sample <sample_name> --output <tsv_path>
```

All arguments are required. Exit 0 on success (including when no variants pass threshold); non-zero on error.

## Procedure

1. Align reads to the reference using `tools/align.py` (or an equivalent method you implement). The aligner produces a pileup TSV with columns: `pos  ref  A  C  G  T  ins  del  depth`.
2. Call variants at each position where **depth ≥ 20** and **VAF ≥ 0.20**. Call SNVs (non-ref base), insertions (from the `ins` column), and deletions (from the `del` column). Merge adjacent single-base deletions that are contiguous and above threshold into one multi-base range deletion.
3. For each called variant, annotate following `docs/nomenclature.md` exactly:
   - Determine which gene and exon the variant falls in using `ref/genes.tsv`.
   - Convert the genomic position to a coding (`c.`) coordinate. Coding coordinates are 1-based; `c.1` is the first base of the start codon (ATG) in transcript orientation.
   - For minus-strand genes, `c.1` is the **3'-most genomic position** (highest genomic coordinate). Alleles are reported in transcript orientation (reverse-complemented from the genomic forward strand).
   - For multi-exon genes, coding coordinates are continuous; intron bases are not counted. For minus-strand genes, exon 1 in transcript order is the exon with the highest genomic positions.
   - Apply the **3' rule** for indels in repetitive sequences: shift to the most 3' position in coding coordinates. For plus-strand genes this is the **highest genomic position**; for minus-strand genes this is the **lowest genomic position**.
   - Compute the protein consequence using the standard codon table with **three-letter amino acid codes**.
4. Output a TSV following `docs/sop.md`.

## Output Format

Header (exact, tab-separated, in this order):

```
Sample	Gene	HGVS_cDNA	HGVS_Protein	Type	Depth	Alt_Depth	VAF
```

- **Sample**: value from `--sample`
- **Gene**: gene name from `ref/genes.tsv`
- **HGVS_cDNA**: `c.` notation per `docs/nomenclature.md`
- **HGVS_Protein**: `p.` notation per `docs/nomenclature.md`
- **Type**: one of SNV, INS, DEL, MNV, COMPLEX
- **Depth**: integer, total reads at the variant position
- **Alt_Depth**: integer, reads supporting the variant
- **VAF**: `Alt_Depth / Depth` rounded to **2 decimal places** (e.g. `0.45`, not `45` or `0.449`)

Sort rows by numeric `c.` coordinate ascending within each gene, then alphabetically by gene name. If no variants pass threshold, output is the header row only.

## Key Rules (stated in `docs/nomenclature.md` and `docs/sop.md`)

- Coding coordinates are 1-based; `c.1` = first base of the start codon (ATG) in transcript orientation.
- For minus-strand genes, `c.1` = highest genomic position of the CDS. Alleles are reverse-complemented to transcript orientation.
- The 3' rule shifts indels in repeats to the most 3' position **in coding coordinates**. For minus-strand genes, most 3' = **lowest genomic position**, not the highest.
- Multi-exon coding coordinates are continuous; intron bases are skipped, regardless of strand.
- In-frame deletions (length divisible by 3): `p.RefAA1_RefAA2del` (or `p.RefAAdel` for single amino acid). **Do NOT use frameshift notation.**
- Synonymous: `p.=`; Missense: `p.RefAAcodonNumNewAA`; Nonsense: `p.RefAAcodonNum*`; Frameshift: `p.RefAAcodonNumfs`.
- Minimum depth: 20×. Minimum VAF: 0.20. Both must be met.
- Annotations must be computed from the aligned reads. The file `results/old_summary.tsv` contains outdated annotations and **must not be used** as a source of annotations (SOP §3.4).

def rev_comp(s):
    return ''.join(COMP[b] for b in reversed(s))

def coding_to_genomic(gene_name, c_pos):
    gene = GENES[gene_name]
    exons = gene['exons']
    c = 0
    if gene['strand'] == '+':
        for es, ee in exons:
            el = ee - es + 1
            if c + el >= c_pos:
                return es + (c_pos - c - 1)
            c += el
    else:
        for es, ee in exons:
            el = ee - es + 1
            if c + el >= c_pos:
                return ee - (c_pos - c - 1)
            c += el
    return None

def genomic_to_coding(gene_name, g_pos):
    gene = GENES[gene_name]
    exons = gene['exons']
    c = 0
    if gene['strand'] == '+':
        for es, ee in exons:
            if es <= g_pos <= ee:
                return c + (g_pos - es + 1)
            c += (ee - es + 1)
    else:
        for es, ee in exons:
            if es <= g_pos <= ee:
                return c + (ee - g_pos + 1)
            c += (ee - es + 1)
    return None

def get_gene_at(ref, g_pos):
    for gn, gd in GENES.items():
        for es, ee in gd['exons']:
            if es <= g_pos <= ee:
                return gn
    return None

def get_transcript_base(ref, gene_name, c_pos):
    g = coding_to_genomic(gene_name, c_pos)
    base = ref[g - 1]
    if GENES[gene_name]['strand'] == '-':
        return COMP[base]
    return base

def set_transcript_codon(ref, gene_name, codon_num, codon_seq):
    c_start = (codon_num - 1) * 3 + 1
    for i, base in enumerate(codon_seq):
        c_pos = c_start + i
        g_pos = coding_to_genomic(gene_name, c_pos)
        if GENES[gene_name]['strand'] == '+':
            ref[g_pos - 1] = base
        else:
            ref[g_pos - 1] = COMP[base]

def simulate_reads(ref, gene_name, variants, rng, n_reads_target=80):
    gene = GENES[gene_name]
    exons = gene['exons']
    amp_start = max(0, min(e[0] for e in exons) - 50)
    amp_end = min(REF_LEN - 1, max(e[1] for e in exons) + 50)
    amp_len = amp_end - amp_start + 1
    n_reads = max(int(n_reads_target * amp_len / READ_LEN), n_reads_target)
    above = [v for v in variants if not v.get('below_threshold')]
    below = [v for v in variants if v.get('below_threshold')]
    reads = []
    for _ in range(n_reads):
        start_0 = rng.randint(amp_start, max(amp_start, amp_end - READ_LEN))
        seq = list(ref[start_0:start_0 + READ_LEN])
        for v in above:
            if rng.random() < v['alt_depth'] / v['depth']:
                _apply_variant(ref, seq, start_0, v)
        for v in below:
            if rng.random() < v['alt_depth'] / v['depth']:
                _apply_variant(ref, seq, start_0, v)
        for j in range(len(seq)):
            if rng.random() < 0.001:
                seq[j] = rng.choice([b for b in 'ACGT' if b != seq[j]])
        while len(seq) < READ_LEN:
            ext = start_0 + len(seq)
            seq.append(ref[ext] if ext < REF_LEN else 'A')
        seq = seq[:READ_LEN]
        reads.append((''.join(seq), '?' * READ_LEN))
    return reads

def _apply_variant(ref, seq, start_0, var):
    g0 = var['genomic'] - 1
    if var['type'] == 'SNV':
        idx = g0 - start_0
        if 0 <= idx < len(seq):
            seq[idx] = var['alt_fwd']
    elif var['type'] == 'DEL':
        idx = g0 - start_0
        dlen = var['del_len']
        if 0 <= idx < len(seq):
            del seq[idx:idx+dlen]
            ext_start = start_0 + len(seq)
            for j in range(dlen):
                seq.append(ref[ext_start + j] if ext_start + j < REF_LEN else 'A')
    elif var['type'] == 'INS':
        idx = g0 - start_0
        if 0 <= idx < len(seq):
            for k, b in enumerate(var['ins_seq_fwd']):
                seq.insert(idx + 1 + k, b)
            while len(seq) > READ_LEN:
                seq.pop()

def find_repeat_extent(ref, gene_name, c_pos, base):
    cds_len = sum(ee - es + 1 for es, ee in GENES[gene_name]['exons'])
    left = right = c_pos
    while left > 1 and get_transcript_base(ref, gene_name, left - 1) == base:
        left -= 1
    while right < cds_len and get_transcript_base(ref, gene_name, right + 1) == base:
        right += 1
    return left, right

def apply_3prime_rule_del(ref, gene_name, c_start, del_len):
    c_end = c_start + del_len - 1
    if del_len == 1:
        base = get_transcript_base(ref, gene_name, c_start)
        left, right = find_repeat_extent(ref, gene_name, c_start, base)
        if right - left + 1 >= 2:
            c_start = right
            c_end = c_start
    else:
        motif = ''.join(get_transcript_base(ref, gene_name, c_start + i) for i in range(del_len))
        if len(set(motif)) == 1:
            base = motif[0]
            left, right = find_repeat_extent(ref, gene_name, c_start, base)
            if right - left + 1 > del_len:
                c_start = right - del_len + 1
                c_end = right
    return c_start, c_end

def apply_3prime_rule_ins(ref, gene_name, c_left, ins_transcript):
    ins_len = len(ins_transcript)
    cds_len = sum(ee - es + 1 for es, ee in GENES[gene_name]['exons'])
    base_at_left = get_transcript_base(ref, gene_name, c_left)
    if ins_len == 1 and ins_transcript == base_at_left:
        left, right = find_repeat_extent(ref, gene_name, c_left, base_at_left)
        if right - left + 1 >= 2:
            return right
    if c_left + 1 <= cds_len:
        base_at_right = get_transcript_base(ref, gene_name, c_left + 1)
        if ins_len == 1 and ins_transcript == base_at_right:
            left, right = find_repeat_extent(ref, gene_name, c_left + 1, base_at_right)
            if right - left + 1 >= 2:
                return right
    return c_left

def annotate_variant(ref, var):
    gene_name = var['gene']
    gene = GENES[gene_name]
    strand = gene['strand']
    depth = var['depth']
    alt_depth = var['alt_depth']
    vaf = round(alt_depth / depth, 2)
    if var['type'] == 'SNV':
        g_pos = var['genomic']
        c_pos = genomic_to_coding(gene_name, g_pos)
        ref_fwd = ref[g_pos - 1]
        alt_fwd = var['alt_fwd']
        if strand == '+':
            ref_t, alt_t = ref_fwd, alt_fwd
        else:
            ref_t, alt_t = COMP[ref_fwd], COMP[alt_fwd]
        hgvs_c = f"c.{c_pos}{ref_t}>{alt_t}"
        var_type = 'SNV'
        codon_num = (c_pos - 1) // 3 + 1
        csc = (codon_num - 1) * 3 + 1
        ref_codon = ''.join(get_transcript_base(ref, gene_name, csc + i) for i in range(3))
        mc = list(ref_codon)
        mc[c_pos - csc] = alt_t
        mut_codon = ''.join(mc)
        ref_aa = CODON_TABLE.get(ref_codon, '?')
        mut_aa = CODON_TABLE.get(mut_codon, '?')
        if ref_aa == mut_aa:
            hgvs_p = 'p.='
        elif mut_aa == '*':
            hgvs_p = f"p.{ref_aa}{codon_num}*"
        else:
            hgvs_p = f"p.{ref_aa}{codon_num}{mut_aa}"
    elif var['type'] == 'DEL':
        g_start = var['genomic']
        del_len = var['del_len']
        c_start = genomic_to_coding(gene_name, g_start)
        c_start, c_end = apply_3prime_rule_del(ref, gene_name, c_start, del_len)
        if del_len == 1:
            ref_base_t = get_transcript_base(ref, gene_name, c_start)
            hgvs_c = f"c.{c_start}del{ref_base_t}"
        else:
            hgvs_c = f"c.{c_start}_{c_end}del"
        var_type = 'DEL'
        codon_num = (c_start - 1) // 3 + 1
        csc = (codon_num - 1) * 3 + 1
        ref_codon = ''.join(get_transcript_base(ref, gene_name, csc + i) for i in range(3))
        ref_aa = CODON_TABLE.get(ref_codon, '?')
        if del_len % 3 == 0:
            cns = (c_start - 1) // 3 + 1
            cne = (c_end - 1) // 3 + 1
            cs = ''.join(get_transcript_base(ref, gene_name, (cns-1)*3+1+i) for i in range(3))
            ce = ''.join(get_transcript_base(ref, gene_name, (cne-1)*3+1+i) for i in range(3))
            aas = CODON_TABLE.get(cs, '?')
            aae = CODON_TABLE.get(ce, '?')
            if cns == cne:
                hgvs_p = f"p.{aas}{cns}del"
            else:
                hgvs_p = f"p.{aas}{cns}_{aae}{cne}del"
        else:
            hgvs_p = f"p.{ref_aa}{codon_num}fs"
    elif var['type'] == 'INS':
        g_pos = var['genomic']
        ins_fwd = var['ins_seq_fwd']
        ins_len = len(ins_fwd)
        if strand == '+':
            ins_t = ins_fwd
            c_left = genomic_to_coding(gene_name, g_pos)
        else:
            ins_t = rev_comp(ins_fwd)
            c_left = genomic_to_coding(gene_name, g_pos + 1)
        c_left = apply_3prime_rule_ins(ref, gene_name, c_left, ins_t)
        c_right = c_left + 1
        hgvs_c = f"c.{c_left}_{c_right}ins{ins_t}"
        var_type = 'INS'
        codon_num = (c_left - 1) // 3 + 1
        csc = (codon_num - 1) * 3 + 1
        ref_codon = ''.join(get_transcript_base(ref, gene_name, csc + i) for i in range(3))
        ref_aa = CODON_TABLE.get(ref_codon, '?')
        if ins_len % 3 == 0:
            hgvs_p = f"p.{ref_aa}{codon_num}ins"

        raa = CODON_TABLE.get(rc, '?'); maa = CODON_TABLE.get(mc, '?')
        if raa == maa: hp = 'p.='
        elif maa == '*': hp = f"p.{raa}{cn}*"
        else: hp = f"p.{raa}{cn}{maa}"
    elif vt == 'DEL':
        gs = var['genomic']; dl = var['del_len']
        c_start = genomic_to_coding(gene, gs)
        if strand == '-':
            c_end = c_start; c_start = c_end - dl + 1
        else:
            c_end = c_start + dl - 1
        c_start, c_end = apply_3p_del(ref, gene, c_start, dl)
        if dl == 1:
            rb = get_tbase(ref, gene, c_start); hc = f"c.{c_start}del{rb}"
        else:
            hc = f"c.{c_start}_{c_end}del"
        vtype = 'DEL'
        cn = (c_start - 1) // 3 + 1; csc = (cn - 1) * 3 + 1
        rc = ''.join(get_tbase(ref, gene, csc + i) for i in range(3))
        raa = CODON_TABLE.get(rc, '?')
        if dl % 3 == 0:
            cns = (c_start - 1) // 3 + 1; cne = (c_end - 1) // 3 + 1
            cs = ''.join(get_tbase(ref, gene, (cns-1)*3+1+i) for i in range(3))
            ce = ''.join(get_tbase(ref, gene, (cne-1)*3+1+i) for i in range(3))
            aas = CODON_TABLE.get(cs, '?'); aae = CODON_TABLE.get(ce, '?')
            hp = f"p.{aas}{cns}del" if cns == cne else f"p.{aas}{cns}_{aae}{cne}del"
        else:
            hp = f"p.{raa}{cn}fs"
    elif vt == 'INS':
        gp = var['genomic']; ifq = var['ins_seq_fwd']; il = len(ifq)
        if strand == '+':
            it = ifq; c_left = genomic_to_coding(gene, gp)
        else:
            it = rev_comp(ifq); c_left = genomic_to_coding(gene, gp + 1)
        c_left = apply_3p_ins(ref, gene, c_left, it)
        c_right = c_left + 1
        hc = f"c.{c_left}_{c_right}ins{it}"; vtype = 'INS'
        cn = (c_left - 1) // 3 + 1; csc = (cn - 1) * 3 + 1
        rc = ''.join(get_tbase(ref, gene, csc + i) for i in range(3))
        raa = CODON_TABLE.get(rc, '?')
        if il % 3 == 0:
            hp = f"p.{raa}{cn}ins"
            for i in range(0, il, 3): hp += CODON_TABLE.get(it[i:i+3], '?')
        else:
            hp = f"p.{raa}{cn}fs"
    return {'Gene': gn, 'HGVS_cDNA': hc, 'HGVS_Protein': hp,
            'Type': vtype, 'Depth': depth, 'Alt_Depth': alt_depth, 'VAF': vaf}

def sim_reads(ref, gn, gene, variants, rng, n_target=80):
    exons = gene['exons']
    amp_s = max(0, min(e[0] for e in exons) - 50)
    amp_e = min(len(ref) - 1, max(e[1] for e in exons) + 50)
    amp_len = amp_e - amp_s + 1
    n = max(int(n_target * amp_len / 150), n_target)
    above = [v for v in variants if not v.get('below_threshold')]
    below = [v for v in variants if v.get('below_threshold')]
    reads = []
    for _ in range(n):
        s0 = rng.randint(amp_s, max(amp_s, amp_e - 150))
        seq = list(ref[s0:s0 + 150])
        for v in above:
            if rng.random() < v['alt_depth'] / v['depth']:
                _apply_var(ref, seq, s0, v)
        for v in below:
            if rng.random() < v['alt_depth'] / v['depth']:
                _apply_var(ref, seq, s0, v)
        for j in range(len(seq)):
            if rng.random() < 0.001:
                seq[j] = rng.choice([b for b in 'ACGT' if b != seq[j]])
        while len(seq) < 150:
            ext = s0 + len(seq); seq.append(ref[ext] if ext < len(ref) else 'A')
        seq = seq[:150]
        reads.append((''.join(seq), '?' * 150))
    return reads

def _apply_var(ref, seq, s0, v):
    g0 = v['genomic'] - 1
    if v['type'] == 'SNV':
        idx = g0 - s0
        if 0 <= idx < len(seq): seq[idx] = v['alt_fwd']
    elif v['type'] == 'DEL':
        idx = g0 - s0; dl = v['del_len']
        if 0 <= idx < len(seq):
            del seq[idx:idx+dl]
            es = s0 + len(seq)
            for j in range(dl): seq.append(ref[es + j] if es + j < len(ref) else 'A')
    elif v['type'] == 'INS':
        idx = g0 - s0
        if 0 <= idx < len(seq):
            for k, b in enumerate(v['ins_seq_fwd']): seq.insert(idx + 1 + k, b)
            while len(seq) > 150: seq.pop()

def write_fq(reads, path, sn):
    with open(path, 'w') as f:
        for i, (seq, qual) in enumerate(reads):
            f.write(f"@{sn}_read_{i+1}\n{seq}\n+\n{qual}\n")

def compute_expected(ref, genes, variants, sn):
    above = [v for v in variants if not v.get('below_threshold')]
    rows = []
    for v in above:
        ann = ref_annotate(ref, v['gene'], genes[v['gene']], v)
        ann['Sample'] = sn; rows.append(ann)
    def sk(r):
        cs = r['HGVS_cDNA'].replace('c.',''); ns = ''
        for ch in cs:
            if ch.isdigit(): ns += ch
            else: break
        return (r['Gene'], int(ns) if ns else 0)
    rows.sort(key=sk)
    return rows

        '--reference', REF_PATH, '--annotation', GENES_PATH,

def parse_tsv(path):
    rows = []
    with open(path) as f:
        header = f.readline().strip()
        for line in f:
            line = line.rstrip('\n')
            if line: rows.append(line.split('\t'))
    return header, rows

def _cmp_ann(rows, expected):
    if len(rows) != len(expected):
        return f"Row count: {len(rows)} vs {len(expected)}"
    for i, (a, e) in enumerate(zip(rows, expected)):
        for j, col in enumerate(['Gene','HGVS_cDNA','HGVS_Protein','Type']):
            if a[j] != e[col]: return f"Row {i} {col}: '{a[j]}' vs '{e[col]}'"
    return None

def test_practice_covers_hidden_cases():
    ref = parse_fasta(REF_PATH)
    genes = parse_genes(GENES_PATH)
    counts = {'vt_snv':0,'vt_indel':0,'vt_repeat':0,'pos_mid':0,'pos_boundary':0,'pos_exon':0,
              'str_plus':0,'str_minus':0,'str_minus_fs':0,'neg':0}
    for i in range(1,7):
        path = f'/app/samples/practice/P0{i}/expected_report.tsv'
        _, rows = parse_tsv(path)
        for r in rows:
            gene = r[0]; hc = r[1]; vtype = r[3]
            gene_data = genes[gene]; strand = gene_data['strand']
            cs = hc.replace('c.',''); ns = ''
            for ch in cs:
                if ch.isdigit(): ns += ch
                else: break
            c_num = int(ns) if ns else 0
            if vtype == 'SNV': counts['vt_snv'] += 1
            elif 'ins' in hc or 'del' in hc:
                if strand == '+' and vtype in ('DEL','INS'):
                    base = get_tbase(ref, gene_data, c_num)
                    l, rr = find_repeat(ref, gene_data, c_num, base)
                    if rr - l + 1 >= 2: counts['vt_repeat'] += 1
                    else: counts['vt_indel'] += 1
                elif vtype in ('DEL','INS'):
                    counts['vt_indel'] += 1
                else: counts['vt_indel'] += 1
            pos_in_codon = (c_num - 1) % 3 + 1
            cds = sum(ee-es+1 for es,ee in gene_data['exons'])
            near_edge = False
            for es, ee in gene_data['exons']:
                cg = genomic_to_coding(gene_data, es); ce2 = genomic_to_coding(gene_data, ee)
                lo, hi = min(cg,ce2), max(cg,ce2)
                if abs(c_num - lo) <= 5 or abs(c_num - hi) <= 5: near_edge = True
            if near_edge: counts['pos_exon'] += 1
            elif pos_in_codon == 3: counts['pos_boundary'] += 1
            else: counts['pos_mid'] += 1
            if strand == '+': counts['str_plus'] += 1
            elif vtype in ('DEL','INS'):
                dl_or_il = 1
                if 'del' in hc and '_' in hc:
                    parts = hc.split('_'); dl_or_il = int(parts[1].replace('del','')) - int(parts[0].replace('c.','')) + 1
                if dl_or_il % 3 != 0: counts['str_minus_fs'] += 1
                else: counts['str_minus'] += 1
            else: counts['str_minus'] += 1
        fq_path = f'/app/samples/practice/P0{i}/reads.fq'
        with open(fq_path) as fq:
            n_reads = sum(1 for line in fq if line.startswith('@'))
        counts['neg'] += 1
    for k, v in counts.items():
        assert v >= 3, f"Practice coverage too low for {k}: {v} (need >=3)"

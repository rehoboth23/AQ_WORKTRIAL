# Shift Scheduling Roster Engine

## Goal

A compiled shift-scheduling engine at `/usr/local/bin/roster` produces weekly staff rosters from schedule input files. Your task is to write a Python reimplementation at `/app/roster.py` that produces **byte-for-byte identical stdout and exit status** to the reference binary for any valid schedule input of the kinds shown in `/app/sample_schedule.txt`.

## Interface

- **Invocation:** `python3 /app/roster.py <input_file>`
- **Input:** A schedule file path given as the first command-line argument
- **Output:** Written to stdout
- **Exit status:** 0 on success, 1 on error (missing argument or unreadable file)

## Input Format

The input file contains four sections, each beginning with a header line on its own. Fields within a line are whitespace-separated.

### STAFF
`id name role skill max_hrs`
- `id` — staff identifier (e.g., `S1`)
- `name` — staff name (single word)
- `role` — `senior` or `junior`
- `skill` — skill identifier (e.g., `A`, `B`)
- `max_hrs` — maximum weekly hours as a number (e.g., `40`)

### SHIFTS
`id day start end skill slots`
- `id` — shift identifier (e.g., `SH1`)
- `day` — day of week: `Mon`, `Tue`, `Wed`, `Thu`, `Fri`, `Sat`, `Sun`
- `start` — start time `HH:MM` (e.g., `08:00`)
- `end` — end time `HH:MM`; may be earlier than `start` if the shift crosses midnight (e.g., `06:00`)
- `skill` — required skill (e.g., `A`, `B`, `C`)
- `slots` — number of staff needed (positive integer)

### PREFERENCES
`staff_id shift_id score`
- `score` — integer from 1 to 5

### HOLIDAYS
`staff_id day`

## Output Format

Two sections are printed to stdout:

### ROSTER
- Header line: `ROSTER`
- One line per shift (in the order the engine processes them): `shift_id` followed by space-separated assigned staff IDs, or `---` for each unfilled slot

### SUMMARY
- Header line: `SUMMARY`
- One line per staff member with at least one assignment: `staff_id hours overtime shift_count`
  - `hours` — total hours with one decimal place (e.g., `8.0`)
  - `overtime` — `yes` or `no`
  - `shift_count` — number of shifts assigned

## Constraints

1. `/app/roster.py` must **not** invoke `/usr/local/bin/roster` or any other external program.
2. The reference binary will be **removed** before your script is evaluated.
3. Your script must handle any valid input of the kinds shown in `/app/sample_schedule.txt`.
4. Output must be byte-for-byte identical, including all whitespace and newlines.

## Approach

1. Study `/app/sample_schedule.txt` to see all input kinds the engine handles.
2. Run `/usr/local/bin/roster` on the sample file and on your own crafted inputs to observe behavior.
3. Probe systematically: vary one thing at a time (preference scores, shift durations, night vs day shifts, holidays, full-time vs part-time staff, multi-slot shifts, staff with and without preferences, skills with no matching staff).
4. Implement `/app/roster.py` to match the binary's behavior exactly.
5. Verify your implementation against the binary on many diverse inputs before you finish.

def gen_case(rng):
    lines = []
    days = ['Mon', 'Tue', 'Wed', 'Thu', 'Fri', 'Sat', 'Sun']

    num_staff = rng.randint(4, 12)
    staff_ids = []
    lines.append("STAFF")
    for i in range(num_staff):
        sid = "S%d" % (i + 1)
        name = "Name%d" % (i + 1)
        role = rng.choice(['senior', 'junior'])
        skill = rng.choice(['A', 'B'])
        if rng.random() < 0.4:
            max_hrs = rng.choice([10, 15, 20, 25, 30, 35])
        else:
            max_hrs = 40
        lines.append("%s %s %s %s %d" % (sid, name, role, skill, max_hrs))
        staff_ids.append(sid)

    num_shifts = rng.randint(3, 10)
    shift_ids = []
    lines.append("SHIFTS")
    for i in range(num_shifts):
        shid = "SH%d" % (i + 1)
        day = rng.choice(days)
        if rng.random() < 0.3:
            start_h = rng.choice([20, 21, 22, 23])
        else:
            start_h = rng.choice([6, 7, 8, 9, 10, 12, 14, 16])
        start_m = rng.choice([0, 15, 20, 30, 45, 50])
        start = "%02d:%02d" % (start_h, start_m)
        start_total = start_h * 60 + start_m
        if rng.random() < 0.3:
            end_h = rng.choice([4, 5, 6, 7, 8])
            end_m = rng.choice([0, 20, 30, 40, 50])
        else:
            duration = rng.choice([120, 180, 240, 300, 320, 360, 400, 420, 480, 500, 280, 250])
            end_total = (start_total + duration) % 1440
            end_h = end_total // 60
            end_m = end_total % 60
        end = "%02d:%02d" % (end_h, end_m)
        if rng.random() < 0.15:
            skill = rng.choice(['A', 'B', 'C'])
        else:
            skill = rng.choice(['A', 'B'])
        slots = rng.randint(1, 3)
        lines.append("%s %s %s %s %s %d" % (shid, day, start, end, skill, slots))
        shift_ids.append(shid)

    lines.append("PREFERENCES")
    for sid in staff_ids:
        if rng.random() < 0.7:
            for shid in shift_ids:
                if rng.random() < 0.4:
                    score = rng.randint(1, 5)
                    lines.append("%s %s %d" % (sid, shid, score))

    lines.append("HOLIDAYS")

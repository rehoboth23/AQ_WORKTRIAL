# Reaction Rate Constant Fitting

You are a researcher in a chemical kinetics lab. A three-step first-order reaction network has been studied in 20 batch reactor experiments. Determine the three rate constants by fitting the experimental time-series data, then create a prediction pipeline using the lab's existing Fortran 77 integrator.

## Reaction Network

    Step 1:  A → B    (rate constant k1, per second)
    Step 2:  B → C    (rate constant k2, per second)
    Step 3:  B → A    (rate constant k3, per second)

Governing ODEs:

    dA/dt = −k1·A + k3·B
    dB/dt =  k1·A − (k2 + k3)·B
    dC/dt =  k2·B

Mass is conserved: A(t) + B(t) + C(t) = A(0) + B(0) + C(0).

## Your Tasks

1. **Fit the rate constants.** Determine k1, k2, k3 by fitting all 20 practice experiments. Save the result as `/app/constants.json` with keys `"k1"`, `"k2"`, `"k3"`, each a positive float in **per-second** units.

2. **Create a prediction script.** Create `/app/predict.sh` (executable) that:
   - Accepts a condition-file path as its first argument (`$1`).
   - The condition file has exactly two lines:
     - Line 1: `A0 B0 C0` (three space-separated floats, mol/L)
     - Line 2: `t_end nsteps` (a float and an integer, seconds and output-step count)
   - Calls the lab's Fortran integrator at `/app/integrator/reactor`.
   - Writes to stdout: a header line `time A B C`, then exactly `nsteps + 1` data lines, each containing four space-separated floating-point numbers.

## Acceptance Criterion

Predictions on **unseen** starting conditions must match the true concentration curves within **7% max relative error** per species per time point, using the metric:

    |predicted − true| / max(true, 0.01)

The maximum over all species and time points for a given condition must be below 7%.

## Resources

- **Integrator source, Makefile, and README:** `/app/integrator/`
- **Practice experiment data:** `/app/data/practice/R01.csv` through `R20.csv` (columns: time, A, B, C)
- **Conditions summary:** `/app/data/practice/conditions.csv`
- **Lab notes:** `/app/docs/lab_notes.txt`

## Important

- Build the integrator with `make` in `/app/integrator/`. The binary is **not** pre-built.
- All rate constants are **per second** (not per minute or per hour).
- The integrator input-deck format is documented in `/app/integrator/README`. **Read it carefully** — the column order for rate constants on Line 2 is specified there and does not follow the natural k1, k2,3 sequence.
- Do not modify the integrator source code; build it as provided.

Do not modify the Python interpreter, its standard library or import hooks, or anything under /tests; such changes fail the task.

import json
import numpy as np
from scipy.integrate import solve_ivp
from scipy.optimize import least_squares
import os

# --- Read practice data ---
conditions = {}
with open('/app/data/practice/conditions.csv') as f:
    header = f.readline()
    for line in f:
        parts = line.strip().split(',')
        name = parts[0]
        A0, B0, C0 = float(parts[1]), float(parts[2]), float(parts[3])
        t_end, nsteps = float(parts[4]), int(parts[5])
        conditions[name] = (A0, B0, C0, t_end, nsteps)

experiments = {}
for name in conditions:
    data = np.loadtxt(f'/app/data/practice/{name}.csv', delimiter=',', skiprows=1)
    experiments[name] = data

# --- ODE right-hand side ---
def ode_rhs(k1, k2, k3):
    def rhs(t, y):
        A, B, C = y
        return [-k1*A + k3*B, k1*A - (k2+k3)*B, k2*B]
    return rhs

# --- Residuals for least_squares fitting ---
NOISE_REL = 0.015
NOISE_FLOOR = 0.005

def residuals(params):
    k1, k2, k3 = params
    rhs = ode_rhs(k1, k2, k3)
    all_res = []
    for name, (A0, B0, C0, t_end, nsteps) in conditions.items():
        data = experiments[name]
        t_data = data[:, 0]
        A_data = data[:, 1]
        B_data = data[:, 2]
        C_data = data[:, 3]

        try:
            sol = solve_ivp(rhs, [0, t_end], [A0, B0, C0],
                          t_eval=t_data, method='RK45',
                          rtol=1e-9, atol=1e-11)
            if sol.y.shape[1] != len(t_data):
                all_res.extend([100.0] * (3 * len(t_data)))
                continue
            A_pred = sol.y[0]
            B_pred = sol.y[1]
            C_pred = sol.y[2]
        except Exception:
            all_res.extend([100.0] * (3 * len(t_data)))
            continue

        # Noise-model weighting: residual = (pred - data) / sigma
        for i in range(len(t_data)):
            sA = max(NOISE_REL * max(abs(A_data[i]), 0.01), NOISE_FLOOR)
            sB = max(NOISE_REL * max(abs(B_data[i]), 0.01), NOISE_FLOOR)
            sC = max(NOISE_REL * max(abs(C_data[i]), 0.01), NOISE_FLOOR)
            all_res.append((A_pred[i] - A_data[i]) / sA)
            all_res.append((B_pred[i] - B_data[i]) / sB)
            all_res.append((C_pred[i] - C_data[i]) / sC)

    return np.array(all_res)

# --- Initial guess and bounds ---
k0 = [0.1, 0.05, 0.02]
bounds = ([0.001, 0.001, 0.001], [5.0, 5.0, 5.0])

# --- Run optimisation ---
result = least_squares(residuals, k0, bounds=bounds,
                       method='trf', max_nfev=20000,
                       ftol=1e-10, xtol=1e-10, gtol=1e-10)

k1_fit, k2_fit, k3_fit = result.x
print(f"Fitted constants: k1={k1_fit:.6f}, k2={k2_fit:.6f}, k3={k3_fit:.6f}")
print(f"Final cost: {result.cost:.6f}")

# --- Save constants ---
with open('/app/constants.json', 'w') as f:
    json.dump({'k1': k1_fit, 'k2': k2_fit, 'k3': k3_fit}, f, indent=2)
print("Saved /app/constants.json")
PYEOF

rm -f /tmp/fit_constants.py

# Pure Python RK4 solver (no external dependencies)
# ===================================================================

def rk4_solve(kab, kba, kbc, A0, B0, C0, t_end, nsteps):
    """Solve the three-step reaction ODE using classical RK4.

    Parameters
    ----------
    kab : k_AB = k1 (forward, A->B, per second)
    kba : k_BA = k3 (reverse, B->A, per second)
    kbc : k_BC = k2 (sink, B->C, per second)

    Returns list of (t, A, B, C) tuples, length nsteps + 1.
    """
    dt_out = t_end / nsteps
    hmax = 0.01
    min_substeps = 100
    nsub = int(dt_out / hmax) + 1
    if nsub < min_substeps:
        nsub = min_substeps
    dt = dt_out / nsub

    # State vector
    sa, sb, sc = A0, B0, C0
    t = 0.0
    results = [(t, sa, sb, sc)]

    for _ in range(nsteps):
        for _ in range(nsub):
            # Stage 1
            f1a = -kab * sa + kba * sb
            f1b = kab * sa - (kbc + kba) * sb
            f1c = kbc * sb
            # Stage 2
            a2 = sa + 0.5 * dt * f1a
            b2 = sb + 0.5 * dt * f1b
            c2 = sc + 0.5 * dt * f1c
            f2a = -kab * a2 + kba * b2
            f2b = kab * a2 - (kbc + kba) * b2
            f2c = kbc * b2
            # Stage 3
            a3 = sa + 0.5 * dt * f2a
            b3 = sb + 0.5 * dt * f2b
            c3 = sc + 0.5 * dt * f2c
            f3a = -kab * a3 + kba * b3
            f3b = kab * a3 - (kbc + k3) * b3
            f3c = kbc * b3
            # Stage 4
            a4 = sa + dt * f3a
            b4 = sb + dt * f3b
            c4 = sc + dt * f3c
            f4a = -kab * a4 + kba * b4
            f4b = kab * a4 - (kbc + kba) * b4
            f4c = kbc * b4
            # Update
            sa += (dt / 6.0) * (f1a + 2.0 * f2a + 2.0 * f3a + f4a)
            sb += (dt / 6.0) * (f1b + 2.0 * f2b + 2.0 * f3b + f4b)
            sc += (dt / 6.0) * (f1c + 0 * f2c + 2. * f3c + f4c)
            t += dt
        results.append((t, sa, sb, sc))

    return results


def max_rel_error(predicted, reference, floor=0.01):
    """Compute max relative error across all species and time points."""
    max_err = 0.0
    for pred, ref in zip(predicted, reference):
        for i in range(1, 4):  # A, B, C
            true_val = abs(ref[i])
            err = abs(pred[i] - ref[i]) / max(true_val, floor)
            max_err = max(max_err, err)
    return max_err


def ground_truth(A0, B0, C0, t_end, nsteps):
    """Compute ground-truth concentration curves using true constants."""
    return rk4_solve(K1_TRUE, K3_TRUE, K2_TRUE, A0, B0, C0, t_end, nsteps)

SHELL_ENV = {"PATH": "/usr/local/bin:/usr/sbin:/usr/bin:/sbin:/bin"}


def run_predict(condition_file_path):
    """Run predict.sh and parse the output."""
    result = subprocess.run(
        ["/app/predict.sh", condition_file_path],
        capture_output=True, text=True, timeout=120,
        env=SHELL_ENV
    )
    assert result.returncode == 0, f"predict.sh failed (exit {result.returncode}): {result.stderr}"

    lines = result.stdout.strip().split('\n')
    assert len(lines) >= 2, "predict.sh output too short"
    assert lines[0].strip() == "time A B C", f"Unexpected header: '{lines[0]}'"

    data = []
    for line in lines[1:]:
        parts = line.split()
        assert len(parts) == 4, f"Expected 4 values, got {len(parts)}: '{line}'"
        data.append((float(parts[0]), float(parts[1]), float(parts[2]), float(parts[3])))
    return data

def test_practice_covers_hidden_cases():
    """Each quirk-matrix level must have >= 3 practice examples."""
    cond_path = "/app/data/practice/conditions.csv"
    with open(cond_path) as f:
        lines = f.readlines()

    reverse_counts = {"low": 0, "medium": 0, "dominant": 0}
    intermediate_counts = {"zero": 0, "small": 0, "large": 0}
    time_counts = {"inside": 0, "longer": 0, "much_longer": 0}

    for line in lines[1:]:
        parts = line.strip().split(',')
        if not parts[0]:
            continue
        A0 = float(parts[1])
        B0 = float(parts[2])
        C0 = float(parts[3])
        t_end = float(parts[4])
        total = A0 + B0 + C0

        # Reverse-step excitation
        ratio = B0 / total if total > 0 else 0
        if ratio < 0.1:
            reverse_counts["low"] += 1
        elif ratio < 0.5:
            reverse_counts["medium"] += 1
        else:
            reverse_counts["dominant"] += 1

        # Initial intermediate
        if B0 == 0:
            intermediate_counts["zero"] += 1
        elif B0 <= 0.3:
            intermediate_counts["small"] += 1
        else:
            intermediate_counts["large"] += 1

        # Time range
        if t_end <= 90:
            time_counts["inside"] += 1
        elif t_end <= 200:
            time_counts["longer"] += 1
        else:
            time_counts["much_longer"] += 1

    for dim_name, counts in [("reverse", reverse_counts),
                             ("intermediate", intermediate_counts),
                             ("time", time_counts)]:
        for level, count in counts.items():
            assert count >= 3, \
                f"{dim_name} level '{level}' has only {count} < 3 practice examples"

# ===================================================================
# Pure Python RK4 solver (no external dependencies)
# ===================================================================

def rk4_solve(kab, kba, kbc, A0, B0, C0, t_end, nsteps):
    """Solve the three-step reaction ODE using classical RK4.

    Parameters
    ----------
    kab : k_AB = k1 (forward, A->B, per second)
    kba : k_BA = k3 (reverse, B->A, per second)
    kbc : k_BC = k2 (sink, B->C, per second)

    Returns list of (t, A, B, C) tuples, length nsteps + 1.
    """
    dt_out = t_end / nsteps
    hmax = 0.01
    min_substeps = 100
    nsub = int(dt_out / hmax) + 1
    if nsub < min_substeps:
        nsub = min_substeps
    dt = dt_out / nsub

    # State vector
    sa, sb, sc = A0, B0, C0
    t = 0.0
    results = [(t, sa, sb, sc)]

    for _ in range(nsteps):
        for _ in range(nsub):
            # Stage 1: evaluate RHS at (t, y)
            f1a = -kab * sa + kba * sb
            f1b =  kab * sa - (kbc + kba) * sb
            f1c =  kbc * sb
            # Stage 2: evaluate RHS at (t+dt/2, y+dt*f1/2)
            a2 = sa + 0.5 * dt * f1a
            b2 = sb + 0.5 * dt * f1b
            c2 = sc + 0.5 * dt * f1c
            f2a = -kab * a2 + kba * b2
            f2b =  kab * a2 - (kbc + kba) * b2
            f2c =  kbc * b2
            # Stage 3: evaluate RHS at (t+dt/2, y+dt*f2/2)
            a3 = sa + 0.5 * dt * f2a
            b3 = sb + 0.5 * dt * f2b
            c3 = sc + 0.5 * dt * f2c
            f3a = -kab * a3 + kba * b3
            f3b =  kab * a3 - (kbc + kba) * b3
            f3c =  kbc * b3
            # Stage 4: evaluate RHS at (t+dt, y+dt*f3)
            a4 = sa + dt * f3a
            b4 = sb + dt * f3b
            c4 = sc + dt * f3c
            f4a = -kab * a4 + kba * b4
            f4b =  kab * a4 - (kbc + kba) * b4
            f4c =  kbc * b4
            # Update: y = y + (dt/6)*(f1 + 2*f2 + 2*f3 + f4)
            sa = sa + (dt / 6.0) * (f1a + 2.0 * f2a + 2.0 * f3a + f4a)
            sb = sb + (dt / 6.0) * (f1b + 2.0 * f2b + 2.0 * f3b + f4b)
            sc = sc + (dt / 6.0) * (f1c + 2.0 * f2c + 2.0 * f3c + f4c)
            t += dt
        results.append((t, sa, sb, sc))

    return results


def max_rel_error(predicted, reference, floor=0.01):
    """Compute max relative error across all species and time points."""
    max_err = 0.0
    for pred, ref in zip(predicted, reference):
        for i in range(1, 4):  # A, B, C
            true_val = abs(ref[i])
            err = abs(pred[i] - ref[i]) / max(true_val, floor)
            max_err = max(max_err, err)
    return max_err


def ground_truth(A0, B0, C0, t_end, nsteps):
    """Compute ground-truth concentration curves using true constants."""
    return rk4_solve(K1_TRUE, K3_TRUE, K2_TRUE, A0, B0, C0, t_end, nsteps)

SHELL_ENV = {"PATH": "/usr/local/bin:/usr/sbin:/usr/bin:/sbin:/bin"}


def run_predict(condition_file_path):
    """Run predict.sh and parse the output."""
    result = subprocess.run(
        ["/app/predict.sh", condition_file_path],
        capture_output=True, text=True, timeout=120,
        env=SHELL_ENV
    )
    assert result.returncode == 0, f"predict.sh failed (exit {result.returncode}): {result.stderr}"

    lines = result.stdout.strip().split('\n')
    assert len(lines) >= 2, "predict.sh output too short"
    assert lines[0].strip() == "time A B C", f"Unexpected header: '{lines[0]}'"

    data = []
    for line in lines[1:]:
        parts = line.split()
        assert len(parts) == 4, f"Expected 4 values, got {len(parts)}: '{line}'"
        data.append((float(parts[0]), float(parts[1]), float(parts[2]), float(parts[3])))
    return data

# Test: practice data covers all quirk-matrix levels
# ===================================================================

def test_practice_covers_hidden_cases():
    """Each quirk-matrix level must have >= 3 practice examples."""
    cond_path = "/app/data/practice/conditions.csv"
    with open(cond_path) as f:
        lines = f.readlines()

    reverse_counts = {"low": 0, "medium": 0, "dominant": 0}
    intermediate_counts = {"zero": 0, "small": 0, "large": 0}
    time_counts = {"inside": 0, "longer": 0, "much_longer": 0}

    for line in lines[1:]:
        parts = line.strip().split(',')
        if not parts[0]:
            continue
        A0 = float(parts[1])
        B0 = float(parts[2])
        C0 = float(parts[3])
        t_end = float(parts[4])
        total = A0 + B0 + C0

        # Reverse-step excitation
        ratio = B0 / total if total > 0 else 0
        if ratio < 0.1:
            reverse_counts["low"] += 1
        elif ratio < 0.5:
            reverse_counts["medium"] += 1
        else:
            reverse_counts["dominant"] += 1

        # Initial intermediate
        if B0 == 0:
            intermediate_counts["zero"] += 1
        elif B0 <= 0.3:
            intermediate_counts["small"] += 1
        else:
            intermediate_counts["large"] += 1

        # Time range
        if t_end <= 90:
            time_counts["inside"] += 1
        elif t_end <= 200:
            time_counts["longer"] += 1
        else:
            time_counts["much_longer"] += 1

    for dim_name, counts in [("reverse", reverse_counts),
                             ("intermediate", intermediate_counts),
                             ("time", time_counts)]:
        for level, count in counts.items():
            assert count >= 3, \
                f"{dim_name} level '{level}' has only {count} < 3 practice examples"

def test_determinism():
    ref1 = rk4_solve(K1_TRUE, K3_TRUE, K2_TRUE, 1.0, 0.0, 0.0, 60.0, 30)
    ref2 = rk4_solve(K1_TRUE, K3_TRUE, K2_TRUE, 1.0, 0.0, 0.0, 60.0, 30)
    for r1, r2 in zip(ref1, ref2):
        for i in range(4):
            assert r1[i] == r2[i], "Ground-truth solver is not deterministic"

    # Different initial conditions must produce different results
    ref3 = rk4_solve(K1_TRUE, K3_TRUE, K2_TRUE, 0.5, 0.5, 0.0, 60.0, 30)
    assert abs(ref1[0][1] - ref3[0][1]) > 1e-10, \
        "Different initial conditions should produce different results"

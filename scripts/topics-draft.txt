# Topic list (2026-10-22). One recipe for every topic: the specification is a runnable reference
# program (a stripped binary) the agent can probe but not read; it builds an equivalent artifact
# that must match the reference on hidden inputs of the sample's kinds. No genre tags.
# Earlier lists (with genre tags) are kept as topics-draft.txt.bak*.

# black-box replacements
a replacement for a vendor's closed-source tax and fee calculator, as a Python library that returns identical quotes for any order
a parser and writer for the binary file format of a legacy export tool, round-tripping byte-identical files
a reimplementation of a legacy account-number validator that accepts and rejects exactly the same inputs
a drop-in replacement for an undocumented line-protocol service running locally, answering every client session exactly as the original does
a reimplementation of a shift-scheduling engine that produces identical rosters, tie-breaks included
a byte-identical encoder and decoder for a legacy compression format whose only implementation is an encoder binary
a library reproducing a pricing and discount engine behind a local HTTP API, quoting identically for any basket
a translation of a legacy access-control configuration into a new rule format that decides every request exactly as the old decider does

# data processing
a bank reconciliation tool that matches two transaction CSVs exactly as the legacy matcher does, tolerances, tie-breaks and unmatched items included
a timesheet-to-payroll converter that reproduces the legacy payroll program's output exactly, week boundaries, overtime and rounding included

# security decisions
a path resolver for a file-sharing service that allows and denies every requested path exactly as the legacy resolver does
an outbound-request allow-list checker that allows and blocks every URL exactly as the legacy gateway's checker does

# legacy batch programs
a nightly branch interest report that reproduces a legacy compiled batch program's report byte for byte from the same customer file
a monthly billing extract that reproduces a legacy extract program's output exactly from the same usage logs

# domain calculations
a bond cash-flow scheduler that reproduces a legacy desk tool's accrual fractions and adjusted payment dates exactly for any trade
a time-scale converter that reproduces a legacy observatory tool's UTC/TAI/TT/GPS conversions exactly, leap seconds included
